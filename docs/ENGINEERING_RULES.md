# Engineering Rules

## Rule 1
One PR = one defined milestone.

## Rule 2
Never implement future PR scope early.

## Rule 3
Never claim unimplemented functionality exists.

## Rule 4
Never fabricate test results.

## Rule 5
Inspect before modifying.

## Rule 6
Security boundaries cannot be bypassed for convenience.

## Rule 7
ML must remain non-load-bearing.

## Rule 8
Privileged operations must be auditable.

## Rule 9
Every PR must validate its changes.

## Rule 10
Every PR must perform a future-scope leakage audit.

## Rule 11
Do not introduce unnecessary dependencies.

## Rule 12
Do not introduce infrastructure complexity without justification.

## Rule 13
Documentation must match actual implementation.

## Rule 14
Failed checks must be investigated rather than hidden.

## Rule 15
The 100-PR sequence must not be compressed.
